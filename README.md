# Тесты API для Яндекс.Прилавок

Данный репозиторий содержит автоматизированные тесты для проверки API Яндекс.Прилавка. 
Основная цель — проверка валидации параметра `firstName` при создании пользователя.

## Стек технологий
* **Язык программирования:** Python 3.x
* **Библиотека для HTTP-запросов:** Requests
* **Фреймворк для тестирования:** Pytest

## Структура проекта
* `configuration.py` — файл с конфигурацией (например, базовый URL).
* `data.py` — тестовые данные (тела запросов, заголовки).
* `sender_stand_request.py` — вспомогательные функции для отправки HTTP-запросов к API.
* `create_user_test.py` — файл с тестами для проверки создания пользователя.
